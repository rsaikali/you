> Discover how your AI really sees you.

**You** is a single-page web app with no backend. Paste a prompt into your favourite AI (ChatGPT, Claude, Gemini…), get back a JSON profile, paste it into the app — a profile card renders entirely client-side.

Live at: [you.saikali.fr](https://you.saikali.fr)

---

## How it works

1. **Copy the prompt** displayed in the sidebar
2. **Paste it into your AI** of choice (links to ChatGPT, Claude, Gemini, Mistral, Grok are provided)
3. **Copy the JSON** the AI returns
4. **Paste it** into the textarea — your profile card appears instantly

No account, no server, no data sent anywhere. Everything runs in your browser.

---

## Profile card

The card renders from a structured JSON object and includes:

- Name, tagline, model name, birth/death years
- Persona, tone, style, linguistic register
- Strengths and weaknesses (lists)
- Contradictions (special styling)
- Speech patterns and forbidden words (chips)
- **20 thematic axes** scored 0–10 with animated progress bars
  (philosophy, politics, science & tech, humor, spirituality, and more)

## Stack

| Layer     | Technology                                   |
|-----------|----------------------------------------------|
| Frontend  | Pure vanilla HTML / CSS / JS (no framework)  |
| i18n      | 5 languages: FR, EN, ES, PT, DE              |
| Fonts     | Quicksand + IBM Plex Mono (Google Fonts)     |
| Server    | Caddy 2 (Alpine Docker image)                |
| Analytics | Umami (self-hosted, PostgreSQL backend)      |

No build step. No transpilation. No node_modules for the app itself.

## Project layout

```
www/            Static files served by Caddy
  index.html    Single page
  style.css     All styles (CSS variables, layout, cards, animations)
  app.js        Client-side logic (JSON parsing, profile renderer)
  i18n.js       Translation strings (FR / EN / ES / PT / DE)
  prompt.js     Prompt text per language
  _dev-seed.js  Dev seed data (loaded only in dev)
  analytics.js  Generated by 'make provision' — do NOT edit by hand

scripts/
  provision.sh  Idempotent — creates the Umami website, generates analytics.js
  push.sh       Rsync + deploy to Raspberry Pi

.github/
  workflows/
    ci.yml      ShellCheck + Docker build + Playwright E2E (on develop)
    cd.yml      SSH deploy to Raspberry Pi (on main)

Dockerfile              FROM caddy:2-alpine
docker-compose.yml      Production stack (caddy + umami + umami-db)
docker-compose.override.yml  Dev overrides — live-mounts ./www
.env.example            Source of truth for all environment variables
Makefile                make up / down / logs / build / provision / open
```

---

## Quick start (dev)

```bash
cp .env.example .env       # adjust values if needed
make up                    # start caddy + umami + umami-db
make provision             # create Umami site, generate www/analytics.js ← once
make open                  # open http://localhost:8200
make logs                  # follow logs
make down                  # stop
```

`docker-compose.override.yml` live-mounts `./www` — no rebuild needed when editing HTML/CSS/JS.

## Environment variables

| Variable               | Purpose                                                        |
|------------------------|----------------------------------------------------------------|
| `DOMAIN`               | Public domain (used by provision.sh for Umami site creation)   |
| `UMAMI_PUBLIC_URL`     | Public URL of the Umami instance (analytics script src)        |
| `UMAMI_INTERNAL_URL`   | Internal URL used by provision.sh to call the Umami API        |
| `UMAMI_ADMIN_PASSWORD` | Umami admin password — change before first provision           |
| `UMAMI_SECRET`         | Umami app secret                                               |
| `UMAMI_DB_PASSWORD`    | PostgreSQL password for the umami user                         |

## CI / CD

| Trigger          | Pipeline                                            |
|------------------|-----------------------------------------------------|
| Push to develop  | ShellCheck · Docker build · Playwright E2E tests    |
| Push to main     | SSH deploy to Raspberry Pi (`make deploy`)          |

GitHub secrets required for CD: `PI_HOST`, `PI_USER`, `PI_SSH_KEY`.

---

## Analytics events (Umami)

| Event              | Triggered when                         |
|--------------------|----------------------------------------|
| `prompt_copied`    | User clicks the copy button            |
| `json_invalid`     | Pasted JSON fails to parse (debounced) |
| `profile_rendered` | A valid profile is drawn               |
| `language_changed` | User switches language                 |

`analytics.js` is generated by `make provision` and is gitignored.
